# داشبورد مؤشرات التعليم في مصر نحو SDG4

مشروع شخصي لتحليل بيانات التعليم في مصر باستخدام بيانات World Bank الرسمية (محدثة تلقائيًا).

## المؤشرات المغطاة:
- معدل الالتحاق بالتعليم الابتدائي
- معدل الالتحاق بالتعليم الثانوي
- معدل الالتحاق بالتعليم العالي
- معدل محو الأمية للبالغين

## كيفية التشغيل:
اضغط على "Open in Colab" أعلاه لتشغيل الداشبورد التفاعلي.

مشروع باستخدام Python، Pandas، وPlotly.
